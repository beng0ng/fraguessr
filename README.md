# Fraguessr

An interactive 3D globe of where perfume ingredients grow, linked to hundreds of famous fragrances, with a daily guessing game, fun facts to collect and perfumes to blend.

This repository is the static website, served by GitHub Pages. It has no build step: `index.html` loads the JavaScript modules beside it. To run it locally, serve this folder with any static server (for example `python3 -m http.server`) and open http://localhost:8000.
